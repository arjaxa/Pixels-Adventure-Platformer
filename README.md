

**Pixel's Adventure | Platformer Game**
=======================
![1000035933](https://github.com/user-attachments/assets/ab9e487d-2637-4408-ae8e-d3b9bb425700)


**Play on:**
------------

https://arigdev.itch.io/pixels-adventure


**Gameplay**
------------

* Use the arrow keys or WASD keys to control your character's movement.
* Find coins to unlock next level and avoid enemies.
* 6 Levels 

**Technical Details**
--------------------

* **Game Engine**: Built using Godot 4.2.2 
* **Programming Language**: GDScript
* **Platforms**: Windows, Web (HTML5)
